Privacy Policy — PYLA

Last updated: 2026-11-06

PYLA does not collect, transmit, or store any personal data.

The application

PYLA is an open source, locally installed firewall GUI for Ubuntu. It has no accounts, no telemetry, no analytics, and no cloud service. All data it handles — firewall rule sets, apply history, settings — lives in a local SQLite database on your own machine.

One network request is made by the application, at your direction: read-only queries to the public Ubuntu Security API to check kernel CVE status for your release. These are standard anonymous HTTPS requests (your OS release and kernel package are part of the query path, as with any package update check). PYLA sends no identifiers about you or your machine.

This website

pyla.space is static content hosted on GitHub Pages. We do not set cookies, embed trackers, or run analytics. GitHub may keep standard server access logs as described in their own privacy policy.

Contact

If you email maintainers@pyla.space, you are choosing to share your email address with us; we use it only to reply and do not share or process it further.
